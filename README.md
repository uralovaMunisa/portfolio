# Munisa Uralova — Creative Developer Portfolio (Bilingual: O'zbekcha & English)

An elite, high-performance personal portfolio website built with **React.js**, **Vite**, **Tailwind CSS**, and **Lucide React**. Designed with a modern luxury dark aesthetic, interactive 3D generative canvas visuals, interactive project component prototypes, smooth animations, audio feedback synthesis, command palette, and full bilingual support (Uzbek & English).

---

## 🌐 Ikki Tilli Tizim (Bilingual Support)

- **O'zbek tili (UZ)**: Standart asosiy til sifatida sozlangan. Barcha bo'limlar, tavsiflar, ko'nikmalar, loyihalar va aloqa formasi sof o'zbek tilida.
- **English (EN)**: Global auditoriya va xalqaro hamkorliklar uchun to'liq ingliz tili versiyasi.
- **Tilni almashtirish**: Navbar, Mobil menyu va Buyruqlar panelida (`Ctrl+K`) joylashgan bitta tugma orqali til bir zumda o'zgaradi va tanlangan til `localStorage`da eslab qolinadi.
